## 1. About Nudgenda

Nudgenda is a local-first calendar assistant that helps users view, create, update, rearrange, and delete calendar events through a timeline and conversational interface. The application is distributed as open-source software and may be installed directly by users.

## 3. Calendar access and actions

On Android, Nudgenda reads and modifies Google calendars that are already synchronized with the device after the user grants Android calendar permission. In a supported web browser, the user may authorize Google Calendar access through Google OAuth.

Calendar actions generated by an AI model may be applied immediately when the user asks Nudgenda to schedule or modify something. AI-generated interpretations can be incorrect. You are responsible for reviewing your calendar and correcting unwanted or inaccurate changes. Do not rely on Nudgenda as the only source of information for critical appointments, medical care, travel, legal deadlines, financial deadlines, or emergencies.

You may revoke Android calendar permission in system settings or revoke Google authorization through your Google Account.

## 4. Voice input and microphone processing

Voice input is optional. When the user taps the microphone, Nudgenda requests Android microphone permission and uses the device's configured speech-recognition service to convert speech into text.

The current voice implementation:

- uses Android's default speech-recognition service;
- does not require Nudgenda to download an offline speech model;
- does not intentionally save or retain an audio recording;
- does not send raw microphone audio to OpenRouter; and
- places the recognized transcript in the message composer for the user to review before sending it.

Android's default speech recognizer may transmit microphone audio to Google, the device manufacturer, or another configured recognition provider for processing. Whether processing happens locally or remotely is controlled by the device, operating system, installed speech service, language, and provider settings. The speech provider's own privacy policy and terms apply to that processing.

If the user presses **Send**, the resulting text transcript is treated like any typed message and may be sent to OpenRouter as described in Section 5. The user can stop listening by tapping the microphone again, deny microphone permission, or revoke permission later through Android settings.

## 5. OpenRouter and AI processing

AI chat is optional and requires the user to provide an OpenRouter API key and select a compatible model or router. The key is stored locally on the user's device. When the user sends a message, Nudgenda sends the following directly to OpenRouter:

- the user's message or voice transcript;
- a limited recent conversation history;
- the current date, time, and timezone;
- relevant calendar-event titles, times, identifiers, descriptions, and calendar labels; and
- any extracted context that the user explicitly previewed and applied from an imported text, Markdown, JSON, or text-based PDF file; and
- instructions needed to return structured calendar actions.

Nudgenda's developer does not receive this request through a Nudgenda-operated server. OpenRouter and the selected model provider may process or retain submitted information according to their own terms, privacy policies, account settings, and model-routing configuration. Users should not submit sensitive information unless they understand and accept those third-party practices.

OpenRouter usage may be free or paid depending on the selected model, account, credits, and current pricing. The user is responsible for charges incurred through their own API key.

## 6. Data stored locally

Depending on platform and enabled features, Nudgenda may store the following locally:

- the user's OpenRouter API key;
- the selected OpenRouter model identifier;
- extracted text and structured summaries from context imports that the user explicitly applies;
- application preferences; and
- temporary interface or conversation state.

On Android, supported secrets are stored using secure device storage. On the web, local settings may be stored in browser local storage. Removing the application, clearing its storage, or clearing browser site data may delete these settings.

Nudgenda does not intentionally collect analytics, advertising identifiers, precise location, contacts, Gmail messages, payment-card information, or raw microphone recordings in the current version.

Context files are selected through the operating system picker and processed locally. Nudgenda limits accepted file and extracted-text size, stores the extracted context rather than the original file, and attempts to discard its temporary picker copy after extraction. Image-only PDFs are not processed because the current version does not include OCR. Users can inspect, replace, or remove active imported context from settings.
